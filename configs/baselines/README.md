# Baseline Policies

This directory stores local baseline-policy JSON files for recurring workflows such as:

- `baseline-imc-set`
- `baseline-imc-show`
- `develop-cycle-imc`

These files are intentionally treated as local machine state because they can contain:

- absolute bot paths
- pinned official artifact paths
- user-specific development baselines

The JSON files in this directory are ignored by git.
